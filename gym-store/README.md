# Ironbase

Static storefront for gym equipment, supplements, and essentials.

Open `index.html` in a browser. Cart and checkout run in the browser only — no payments are processed.

## Connect to Git

```bash
cd gym-store
git init
git add .
git commit -m "Add Ironbase storefront"
git branch -M main
git remote add origin https://github.com/YOUR_USER/YOUR_REPO.git
git push -u origin main
```

Create an empty repo on GitHub or GitLab first, then replace the remote URL.

## Connect it

```bash
mkdir gym-store && cd gym-store
# save the files above, then:
git init
git add .
git commit -m "Add Ironbase storefront"
git branch -M main
```
